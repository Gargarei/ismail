# 🏓 Ping-Pong Game (Python + Pygame)

Двухмерная игра **Ping-Pong** на Python с использованием библиотеки **Pygame**. Простой, но увлекательный способ вспомнить классическую аркаду!

![Ping-Pong Demo](https://img.shields.io/badge/Python-3.8%2B-blue?logo=python)
![Pygame](https://img.shields.io/badge/Pygame-2.0%2B-orange?logo=pygame)
![License](https://img.shields.io/badge/License-MIT-green)

---

## 🎮 Обзор

Этот проект реализует классическую игру **Ping-Pong (Pong)** с двумя игроками:

- **Игрок слева** управляет ракеткой клавишами **W** и **S**.
- **Игрок справа** управляет ракеткой клавишами **↑** и **↓**.
- Цель — отбивать мяч и не давать ему пройти мимо своей ракетки.
- Первый игрок, набравший **5 очков**, побеждает!

## 🛠️ Требования

- Python 3.8 или выше
- Pygame

Установите зависимости командой:

```bash
pip install pygame
```

---

## 🚀 Запуск игры

1. Клонируйте репозиторий:

```bash
git clone https://github.com/ваш-ник/ping-pong-python.git
cd ping-pong-python
```

2. Запустите игру:

```bash
python main.py
```

> ⚠️ Убедитесь, что файл с игрой называется `main.py` (или замените на имя вашего основного файла).

---

## 🎯 Управление

| Действие           | Клавиши |
|--------------------|---------|
| Движение ракетки (игрок 1) | **W / S** |
| Движение ракетки (игрок 2) | **↑ / ↓** |
| Пауза / Возобновление      | **Пробел** |
| Выход                      | **ESC** |
